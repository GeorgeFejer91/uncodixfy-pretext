# Uncodixfy Pretext

A Codex skill for restrained, box-first HTML UI design with required [Pretext](https://github.com/chenglou/pretext) measurement for bounded text on the UI being changed. It nests the original [Uncodixfy](https://github.com/cyxzdev/uncodixfy) aesthetic discipline and Ponytail/YAGNI.

Install the repository as the `uncodixfy-pretext` skill in Codex, then read [SKILL.md](SKILL.md). [Pretext implementation notes](references/pretext.md) are part of the skill. The skill is guidance, not a claim that any existing application has already implemented or verified its text-fitting contract.

Maintainer routing lives in [for-ai/README.md](for-ai/README.md); it is not part of the UI runtime.
